# Лабораторная работа №4

## Тема: Глубокое обучение и трансформерные архитектуры в анализе текстов.

### 1. Цель работы
Освоить применение дистрибутивной семантики, рекуррентных нейронных сетей и современных предобученных трансформеров для анализа текста, а также провести комплексный сравнительный бенчмарк всех изученных в курсе методов.

### 2. Пошаговое текстовое задание

1. Дистрибутивная семантика (Word Embeddings): Обучите собственную модель Word2Vec (или FastText) на корпусе вашего датасета. На примере 5 ключевых слов найдите топ-5 наиболее близких по косинусному расстоянию векторов. Визуализируйте подмножество векторов (не менее 100 слов) на двухмерной плоскости с помощью алгоритма t-SNE, выделив смысловые кластеры.

2. Промежуточный Baseline (Sentence Embeddings): Реализуйте бейзлайн на основе усреднения векторов слов: для каждого документа получите вектор путем вычисления среднего арифметического векторов Word2Vec всех входящих в него слов (Mean Pooling). Обучите Логистическую регрессию на полученных плотных векторах и зафиксируйте метрики.

3. Используя фреймворк PyTorch (или TensorFlow), постройте рекуррентную нейросеть архитектуры BiLSTM или BiGRU для классификации текстов. Сравните два режима работы со слоем Embedding:
   1. Static: Веса инициализируются матрицей из Word2Vec (Шаг 1) и замораживаются (requires_grad=False).
   2. Dynamic: Слой Embedding обучается «с нуля» (from scratch) в процессе решения целевой задачи.

4. Оценка RNN: Обучите сеть на обучающей выборке, контролируя процесс переобучения (выводите графики Loss и F1 на train/validation по эпохам). Используйте технику Early Stopping. Зафиксируйте итоговые метрики качества на тестовой выборке.

5. Дообучение трансформера (Fine-Tuning BERT): Выберите подходящую под язык вашего датасета предобученную модель семейства трансформеров (например, rubert-tiny2 или rubert-base-cased для русского языка) из Hugging Face.

6. Проведение Fine-Tuning: Настройте скрипт обучения (используя библиотеку transformers и класс Trainer или кастомный цикл на PyTorch). Добавьте поверх предобученного трансформера линейный слой классификации и дообучите модель на вашем датасете (допускается взять сбалансированную подвыборку данных для экономии вычислительных ресурсов). Зафиксируйте метрики на тестовой выборке.

7. Сводный бенчмарк и итоговый анализ: Составьте финальную сравнительную таблицу качества работы всех построенных за курс моделей классификации.
