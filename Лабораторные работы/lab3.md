# Лабораторная работа №3

## Тема: Классическое машинное обучение в NLP: векторизация, классификация, полнотекстовый поиск и тематическое моделирование.


### 1. Цель работы
Научиться применять классические статистические подходы для автоматической классификации текстовых документов, построения поисковых систем с ранжированием и извлечения скрытых тем из корпуса.

### 2. Пошаговое текстовое задание

1. Статистическая векторизация: Преобразуйте тексты обучающей и тестовой выборок в числовые векторы двумя способами: с помощью модели «мешка слов» (Bag of Words) и с помощью взвешивания TF-IDF. Жестко соблюдайте методологию: рассчитывайте словарь и частоты (fit) исключительно на обучающей выборке (Train), а для тестовой (Test) применяйте только трансформацию (transform). Сравните получившуюся размерность признакового пространства.

2. Обучение классификаторов: На основе полученных TF-IDF векторов обучите два классических алгоритма машинного обучения на выбор (например, Наивный Байесовский классификатор (Naive Bayes) и Линейный SVM / Логистическая регрессия) для решения целевой задачи вашего датасета (определение тональности, спама, категории и т.д.). Настройте параметры балансировки классов, если в вашем датасете присутствует явный дисбаланс.

3. Оценка качества классификации: Предскажите метки классов на тестовой выборке. Рассчитайте метрики качества: Macro Precision, Macro Recall и Macro F1-score. Обоснуйте в отчете, почему метрика Accuracy не является репрезентативной для вашей задачи. Постройте матрицу ошибок (Confusion Matrix) и проведите качественный анализ ошибок модели (Error Analysis) на 5 конкретных примерах.
   
4. Построение инвертированного индекса: Реализуйте структуру данных «инвертированный индекс» по всему корпусу текстов датасета. Индекс должен сопоставлять каждое уникальное слово со списком идентификаторов документов, в которых оно встречается.

5. Реализация поискового движка BM25: Напишите функцию полнотекстового поиска. Функция должна принимать на вход произвольный текстовый запрос пользователя, находить релевантные документы через инвертированный индекс и ранжировать их по формуле Okapi BM25. Протестируйте поиск на 3 различных запросах, выведите топ-5 результатов для каждого.

6. Тематическое моделирование (LDA): Примените алгоритм Латентного размещения Дирихле (LDA) к вашему корпусу текстов. На основе итеративного вычисления метрики когерентности (Coherence Score, \(C_{V}\)) постройте график зависимости связности тем от их количества K и экспериментально выберите оптимальное число тем.

7. Интерпретация тем: Для каждой из выделенных тем выведите топ-10 слов с наибольшим весом. Дайте текстовое описание и название каждой теме на основе анализа этих слов (например: тема «Логистика», тема «Финансы»).
